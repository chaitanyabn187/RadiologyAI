RadiologyAI — AI-Assisted Radiology Case Prioritization System

About

RadiologyAI is an academic project that demonstrates the use of artificial intelligence to analyze chest X-ray images and organize cases for review.

Features

- Upload chest X-ray images.
- Generate experimental AI findings.
- Display X-ray images and findings on a dashboard.
- Rank cases using model output scores.
- Detect duplicate image uploads.
- Add and delete cases.
- Store case details using SQLite.

Technologies Used

- Python
- Flask
- PyTorch
- TorchXRayVision
- SQLite
- HTML, CSS, JavaScript

How to Run

1. Install Python.
2. Install the required packages:
   "pip install -r requirements.txt"
3. Run the application:
   "python app.py"
4. Open "http://127.0.0.1:5000" in your browser.

Disclaimer

This project is an academic prototype. AI outputs are experimental and are not confirmed diagnoses or intended for clinical decision-making.
